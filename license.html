2. What This Software Does

Designer Dark Mode changes the appearance of the Ignition Designer on the machine where it is installed. It restyles the Designer's own user interface and does not modify, migrate, or rewrite your projects, views, windows, tags, or any other gateway resource. Turning the theme off restores the Designer's stock appearance.
